使用流程

  1. 設定參數並開啟骰子視窗。
  2. 按「播放投擲」，等待骰子停止。
  3. 檢視每顆骰子的朝上點數。
  4. 按「確認並關閉」觸發 onComplete(resultData)；關閉叉號則取消，不回傳完成結果。

整合呼叫範例

DiceRoller.open({
  title: "敏捷檢定",
  count: 2,
  faces: [1, 2, 3, 4, 5, 6],
  renderStyle: 0,
  physics: { gravity: -35, restitution: 0.65 },
  onComplete(result) {
    console.log(result.results, result.total);
  }
});

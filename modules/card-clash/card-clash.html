卡牌數值對戰

傳入雙方角色、碰撞規則與卡片樣式後，由模組內部反覆結算碰撞並呈現戰鬥；一方生命值歸零時回傳結果並關閉。

雙方同時碰撞 內部規則介面 結果回呼與自動收尾

TRY IT

互動展示

啟動一般對戰或自動 Boss 戰。戰鬥在覆蓋介面中進行，結果與每次碰撞狀態會記錄於右側日誌。

戰鬥情境

先編輯雙方角色數值，再選擇手動或自動碰撞。未指定或找不到規則與卡片類型時，模組會使用 basic 預設值。

戰鬥回呼日誌

  1. 等待操作。

操作流程

  1. 選擇一般對戰或 Boss 自動戰。
  2. 手動模式按下「ATTACK (PLAY)」逐次碰撞；自動模式會持續碰撞至戰鬥結束。
  3. 查看日誌中的碰撞傷害與最終勝者；模組完成後會自動關閉戰鬥介面。

整合範例

CardClash.open({
  rule: 'basic',
  type: 'basic',
  player: { name: '勇者', hp: 35, atk: 9, def: 2 },
  enemy: { name: '半獸人', hp: 30, atk: 7, def: 1 },
  onComplete(result) {
    console.log(result.winner, result.rounds);
  }
});
